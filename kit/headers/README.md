# Shared declarations

Any C/C++ headers shipped here are available to the checker. Some kit versions contain only this note; they do not contain the full game's headers.

Your `candidate.cpp` must include the declarations and layouts needed by the assigned function. Use the packet and local brief, and explain uncertain layouts in your submission notes.

Submit through the Iblis service. If a shared header seems wrong, describe the problem in the notes; editing your local copy does not update the build host's copy.
